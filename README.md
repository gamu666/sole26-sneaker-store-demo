# SOLE/26 Sneaker Store Demo

A polished, responsive sneaker e-commerce concept built with self-contained HTML, CSS, and JavaScript.

## Included

- Responsive Nike-inspired product listing
- Colorway hover previews and persistent selections
- Sticky product gallery with size selection
- Cart, checkout, and QPay demo flow
- Local product imagery in `assets/shoes`

## Preview locally

Open `index.html` in a modern browser. No build step or installation is required.
